# EXAMPLE

## **Example: How the Rebate.fun Referral System Works**

#### Step 1 — Referral

* **User A** refers **User B** to Rebate.fun.
* User B registers a CEX account using a Rebate.fun referral code and binds the account to Rebate.fun.

***

### Trading & Fees

On **02/02/2026**, User B trades **$200M** on the CEX.

Trading fee rate: **0.05%**

Total trading fees paid:

> $200M × 0.05% = **$100,000**

***

### Revenue Distribution

The CEX shares **50% of the trading fees** with Rebate.fun:

> $100,000 × 50% = **$50,000**

Distribution of the shared revenue:

• **$40,000** returned to User B as **withdrawable cashback**\
• **$10,000** retained by **Rebate.fun as platform revenue**

***

## Referral Rewards

### Scenario 1 — Standard Member (10%)

If User A is below Gold tier:

User A earns **10% of platform revenue** from User B:

> $10,000 × 10% = **$1,000**

User A receives **$1,000**, which can be:

* Withdrawn, or
* Contributed toward VVIP level progression

***

### Scenario 2 — Gold Tier & Above (25%)

If User A is **Gold tier or above**:

User A earns **25% of platform revenue** from User B:

> $10,000 × 25% = **$2,500**

User A receives **$2,500**, which can be:

* Withdrawn, or
* Contributed toward VVIP level progression to level up faster

***

## Important Notes

* This is a **single-layer referral system**.\
  If User B refers someone else, User A does not earn from that activity.
* Referral rewards are calculated **after cashback and rebate deductions**.

***

## Summary

* **User B** receives cashback/rebate.
* **User A** earns referral rewards (10% or 25% depending on tier).
* Higher tiers earn significantly more.
* Earnings can be withdrawn or used to accelerate VVIP progression.
* The system is transparent, simple, and aligned with ecosystem growth.
